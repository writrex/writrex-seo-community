# Contributing

Thank you for helping improve Writrex SEO.

This is a community and product-feedback repository, not the private application source repository. Contributions here are bug reports, feature requests, documentation improvements and constructive discussion.

## Before creating an issue

1. Search existing issues and discussions.
2. Read the [FAQ](FAQ.md).
3. Confirm the behaviour is reproducible.
4. Remove confidential information.

## A useful bug report includes

- A clear title
- Public webpage URL, where relevant
- Approximate time observed
- Steps that reproduce the issue
- Expected and actual behaviour
- Browser and device details
- A screenshot with sensitive information removed

## A useful feature request includes

- The problem, not just a proposed solution
- Who would benefit
- Why the current workflow is insufficient
- What a good outcome looks like

Never post credentials, API keys, payment details, personal data, private website URLs, customer reports or security vulnerabilities. Follow [SECURITY.md](SECURITY.md) for security concerns.

All participation must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
