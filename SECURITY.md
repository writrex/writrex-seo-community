# Security policy

## Do not report security issues publicly

Do not create a public GitHub issue or discussion for a potential security vulnerability.

Send a private report to [hello@writrex.com](mailto:hello@writrex.com) with the subject `Writrex SEO security report`.

## Include

- Clear description of the concern
- Safe reproduction steps
- Affected public URL or feature
- Approximate time observed
- Safe proof of concept or screenshots with sensitive data removed
- Preferred contact method

Do not include passwords, access tokens, payment information or other sensitive personal data.

We will acknowledge the report, assess it and work toward a fix. Please allow reasonable time for investigation and remediation before public discussion.
