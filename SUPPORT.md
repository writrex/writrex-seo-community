# Getting support

For account or product support, visit [Writrex SEO Support](https://seo.writrex.com/support).

Use GitHub Discussions for general questions, workflows and ideas. Use an issue only for a reproducible bug or a specific feature request.

To help us investigate, include a public webpage URL where relevant, approximate time, expected and actual behaviour, reproduction steps, plus browser and device details.

Do not post passwords, tokens, payment details, private audit reports, personal information or login-only URLs. For security concerns, follow [SECURITY.md](SECURITY.md).
