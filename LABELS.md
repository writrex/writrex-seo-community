# Recommended issue labels

Create these labels in repository **Settings → Issues → Labels** so issue forms can apply them automatically.

| Label | Colour | Use |
| --- | --- | --- |
| `bug` | `d73a4a` | Product defect |
| `feature-request` | `1d76db` | Improvement suggestion |
| `documentation` | `0075ca` | Documentation feedback |
| `needs-triage` | `fbca04` | Awaiting review |
| `needs-information` | `d4c5f9` | More detail required |
| `under-review` | `5319e7` | Being assessed |
| `planned` | `0e8a16` | Accepted for future work |
| `in-progress` | `0052cc` | Actively worked on |
| `released` | `0e8a16` | Available to users |
| `not-planned` | `ffffff` | Not planned |
| `duplicate` | `cfd3d7` | Already reported |
